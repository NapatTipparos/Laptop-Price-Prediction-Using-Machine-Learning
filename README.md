# Laptop Price Prediction Using Machine Learning

## Introduction

This project uses machine learning to predict laptop prices based on hardware specifications and brand information. Laptop prices vary depending on factors such as CPU, RAM, storage, GPU, screen size, and brand, making manual price estimation difficult and inconsistent.

The goal is to build a predictive model that helps users estimate laptop prices and make more informed, data-driven pricing decisions.

## Project Summary

The project involves preprocessing laptop pricing data, selecting relevant features, and comparing three supervised regression algorithms: **Random Forest, Decision Tree, and Linear Regression**.

Random Forest was selected as the preferred model because of its ability to capture complex, non-linear relationships between laptop specifications and prices, reduce overfitting, and provide more stable predictions.

### Objectives

- Predict laptop prices based on hardware specifications and brand.
- Compare the performance and characteristics of different regression algorithms.
- Identify a suitable model for laptop price prediction.
- Support more consistent pricing estimates for buyers and sellers.

### Machine Learning Models

- **Random Forest Regression** — Selected model.
- **Decision Tree Regression** — Evaluated as an alternative.
- **Linear Regression** — Evaluated as a baseline model.

### Features

- CPU
- RAM
- Storage
- GPU
- Screen size
- Brand

### Expected Outcomes

- Estimate laptop prices from product specifications.
- Help buyers assess whether laptop prices are reasonable.
- Help sellers establish more data-driven prices.
- Improve the consistency of laptop price estimation.
